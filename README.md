# OpenFilter: layered navigation for Magento 2 and Hyvä

Free, MIT-licensed, Hyvä-native AJAX layered navigation for Magento 2 and Mage-OS, built on the OpenSearch Magento already ships. No ElasticSuite needed.

> **Status: in development (1.0 planned).** Not ready for production yet.

Planned for 1.0: multi-select filters with correct counts, AJAX that works with Varnish and an enforced CSP, price and decimal sliders, rating / in stock / on sale / new filters, a mobile drawer with "Show N products", SEO-safe URLs (readable names, canonical, robots, nofollow rules) and an admin with diagnostics ("Why is this filter not showing?").

Packages: `iranimij/openfilter` (core), `iranimij/openfilter-hyva` (Hyvä storefront), `iranimij/openfilter-hyva-bundle` (both, plus the shared core `iranimij/module-base`).
